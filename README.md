# UK Public Holidays Lookup

This program fetches UK public holidays for a given year using the GOV.UK bank holidays API.

## Usage

1. Install dependencies (optional; the script uses Python's built-in urllib):

```bash
pip install -r requirements.txt
```

2. Run the program with a year argument:

```bash
py holiday_fetcher.py 2027
```

The program prints the public holidays for the United Kingdom in the requested year.
